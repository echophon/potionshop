00What it is

potionshop plays bursts: short flurries of notes based on clock divisions, each burst's hits snapped forward onto that channel's own quantize grid. Each of its six channels repeatedly fires a small group of hits, then waits, then fires again — the rhythm, pitch, density and tone of every burst comes from a stack of looping value sequences you edit live.

The grid is the primary instrument; the norns screen + three encoders + two keys mirror everything and add fine control. Every channel is the same four-operator FM voice — there are no per-channel voice types.

the grid

16×8. Rows 0–5 are the six channels; the bottom two rows hold transport, page buttons, param select and channel actions.

the screen

E1 picks a channel, E2 walks a cursor, E3 edits, K2/K3 page. Focus is the brightest

the params

The whole instrument is also norns params — visible in the PARAMETERS menu, MIDI-mappable, and saved in PSETs.

▶Getting started

A short walkthrough, starting from a blank slate: clear the channels, launch one, edit it with the picker, then layer in rhythm, density, tone and scale. Each picture shows the grid as you'd see it — the pulsing gold ring marks the key to press.

Reading the lights: brightness shows a value (brighter = higher/louder), a full-bright light is the live playhead or your current selection, and a faint light is an empty slot. That's the whole language — details are in reading the grid.

Start from a blank slate optional

When the script boots it randomizes every channel, so on a fresh start all six rows are already full of scattered values. That's fun to jam on, but for a clean first patch let's wipe every channel back to defaults.

The row-7 buttons on the right are actions — they're armed, not instant. Press CLR and it starts blinking to show it's waiting; then tap each channel on row 6 to clear them one by one. (Press CLR again to disarm without using it.)

▸ press row 7 · col 11 (CLR) — it blinks ▸ then tap row 6 · cols 0–5 to clear all six channels
MAIN CLR armed (blinking) — tap each channel to reset its A sequences

Make a sound

Each of the six rows is a channel — an independent voice. Launch channel 1 to fire it.

Because we just cleared it, the channel sits at its defaults: a single note and reps = 3. A cleared channel fires one burst — three quick hits — then stops. What makes it stop is the length of the reps sequence, not the number: a reps sequence with a single step is single-shot, so it plays its one burst and the launch light flashes, sounds, then releases. Press it again to re-fire. Looping only kicks in once reps has more than one step (step 6) — the next steps build the channel up to that.

▸ press row 6 · col 0  (launch ch1) — hear a 3-hit burst
MAIN ch1 fires one 3-hit burst, then stops (cleared default)

Edit a note

Rows 0–5 are currently showing the note parameter — you can tell because note is lit on row 7 (the param-select row). Channel 1's lit cells are its note steps; their brightness encodes each value.

This list of values is a sequins — a loop the burst reads one value from at a time. Press any step to change it.

▸ press a lit step on ch1
MAIN press a note step on ch1 to edit it

Pick a value

The bottom two rows (6–7) turn into the step picker: a palette of all 32 values for this param, low → high, left → right then down, with every channel row still visible above. The full-bright cell is the step's current value; dim cells are other values already used elsewhere in the sequence.

Press a cell to write it and close the picker. Pressing the already-lit value — the step's current one — removes the step instead.

PICK 32 candidate values — chosen one at full brightness

Add & remove steps

Just past the last step sits a single dim append slot. Press it to add a step — the picker opens on the new one so you can set it straightaway. Longer sequences cycle over more bursts before repeating.

To shorten a sequence, open a step in the picker and press its already-lit current value — the full-bright cell — to delete that step.

Add a few more notes to the sequence & then press the channel launch button to step through the bursts. ▸ press the dim append slot after the last step
MAIN the dim cell after the last step appends a new one

Change the rhythm — div

So far you've only edited pitch. Select the div / reps page on row 7 (col 0). It's a paired page: each channel row shows two lanes side by side — div in the left half (cols 0–7), reps in the right half (cols 8–15). Hits within a burst are spaced 4/div beats apart, so a bigger div means a faster flurry.

Edit it exactly like notes: press a step in the left (div) half, pick a value. Because div is a sequence, the rhythm can change burst to burst. A step of div=4 spaces hits evenly on the beat; div=3 gives a triplet feel.

▸ press row 7 · col 0  (div / reps), then edit a step in the left half
MAIN div / reps page — div in the left half

Change density — reps

The right half of that same div / reps page is reps: how many hits each burst fires before it waits and repeats. Combined with div, this is the heart of the "burst" feel — a few fast hits, then space.

This is what makes the channel loop. While reps has a single step the channel is single-shot (step 1's lone burst). Add a second reps step — press the append slot in the right half and pick a value — and the channel now cycles continuously; the bright playhead starts walking the row.

A reps value of 0 or less is a rest: it fires nothing but still eats 1−reps div-steps of time, so you can pattern silence into the loop.

▸ in the right half of row 7 · col 0, add a 2nd reps step to loop
MAIN reps (right half) with two steps — channel loops, playhead walks

Shape the tone — level & envelopes

The remaining row-7 pages colour the sound, and each is its own sequence:

  • level (col 2) — loudness. It doubles as the "run CV" that drives the geode shaping across a burst's hits.
  • attack / decay (col 3, paired) — the carrier amp envelope: how each note swells and fades.
  • modatk / moddec (col 4, paired) — the modulator envelope: shapes FM brightness over the note independently of the amp.

The voice's static timbre — per-operator ratios and levels — lives on the OP page, not here.

▸ try row 7 · cols 2–4  (level / attack·decay / modatk·moddec)
MAIN level selected — the two envelope pages sit beside it

Choose a scale & root

Press SCALE (row 6, col 14) to open the scale picker. Pick a scale on the top row and a root on the lower piano — your note degrees are mapped through these, so everything stays in key. Press SCALE again to return to MAIN.

Timing is set separately: the QNT page (row 6, col 15) gives each channel its own forward-snap quantize grid (1/3 … 1/32), so channels with different divs can lock to different grids.

▸ press row 6 · col 14  (SCALE) → pick scale + root
SCALE scale presets · degree keys · root piano

You've got the loop — where to next

That's the whole core gesture: launch → select a param → press a step → pick a value. Everything below builds on it. Good next stops:

A / B layers ↗

On the note and level pages the right half is a B layer — an additive offset sequence that variates the A pattern.

PROB ↗

Add chance: skip bursts or hits by probability, and arpeggiate the B note layer with alt-trig "step".

PERF ↗

Per-channel reset, octave shift and playback rate — performance moves that don't touch your sequences.

OP ↗

Per-operator ratios and levels — the static per-channel timbre that gives each voice its identity.

QNT ↗

Per-channel quantize: lock each channel to its own forward-snap grid, from 1/3 to 1/32.

The screen ↗

Drive the same edits from the encoders & keys — a complete second surface that stays in sync with the grid.

01Core concepts

A handful of ideas explain almost every button. Read these once and the pages below stop being arbitrary.

channel

One of six independent voices (rows 0–5 on the grid). Launch it and it loops bursts until stopped. Every channel is the same four-operator FM voice.

burst

One firing event: reps hits spaced 4/div beats apart. After the burst the channel draws fresh values and fires the next one.

sequins

Every sequenced parameter is a looping list of values (a sequins). Each burst pulls the next value from each list, so patterns evolve as the lists cycle at different lengths.

A / B layers

note and level each have an A sequence and a B sequence. B is an additive offset summed onto A every burst (its value set adds a literal 0 = "no offset"), shown in the right half of the row.

rest

A reps value of 0 or less fires nothing but still consumes 1−reps div-steps of time — a deterministic silence, distinct from level=0 and from probability.

algorithm

The FM operator routing — which operators modulate which, and which reach the output. One of 16, set engine-wide in PARAMETERS ▸ VOICE.

geode

Per-hit modulation shaping a burst's amplitude across its hits — transient/sustain/cycle curves derived from the level value. Always on.

quantize

The grid a channel's firing instant snaps forward onto. Per channel, so channels can lock to different grids. Tempo is never changed — only when a hit lands.

probability

Per channel: a burst (or each hit) can be skipped by chance. 25/50/75/100% with a burst-vs-hit toggle.

reset

Optionally rewind a channel's sequences to step 1 every 1/2/4 bars, re-anchoring it to the bar grid so duplicates stay locked.

The sequenced parameters

These are the page-select buttons on row 7 and the lines you edit on the screen. div/reps, attack/decay and modatk/moddec are paired pages (two A-lanes, no B layer); note and level carry A + B.

02Reading the grid

Hardware grids only show brightness, so potionshop speaks in three signals: how bright a key is, whether it blinks, and which row it's on.

Brightness

  • 15 (full): the selected / focused thing, or a live playhead moving through a running channel's steps.
  • mid (4–12): an active value, present step, or available option. On step rows, brightness encodes the value — louder/higher reads brighter.
  • dim (1–3): an empty "append" slot, an inactive option, or a key that exists but isn't selected.
  • off (0): nothing there on this page.

Strobe (blink)

  • fast blink: "you are here" — the page/mode button you're currently inside, or an armed action.
  • slow blink: a latched secondary state — e.g. a per-hit-probability toggle that's on.

Coordinates

This guide labels columns 0–15 and rows 0–7, matching the source. (The physical grid is 1-based; the script converts at the edge.) Channels are rows 0–5 = "ch1–ch6".

03MAIN page — the home view

The default. Rows 0–5 show the selected page's steps for each channel, split into two lanes side by side. Row 6 is transport + page buttons; row 7 is page-select + channel actions.

MAIN editing note — ch3 is running (its playhead lit at full)

Rows 0–5 — channel steps

Each row is one channel, shown as two lanes: the left half (cols 0–7) and the right half (cols 8–15), each up to 8 steps. For note / level the lanes are the A layer (left) and B additive offset (right); for a paired page they're the two members. Lit cells are steps; their brightness encodes the value. The dim cell just past a lane's last step is its append slot. When a channel runs, its current step glows at full as the playhead. The lane you press is the lane you edit — there is no A/B flip.

  • Press a step → opens the step picker to set that step's value.
  • Press the append slot → adds a step and opens the picker on it.
  • In the picker, press the already-lit current value → removes the step.

04Step picker — set one value

Pressing any step (or append slot) on a channel row opens the picker over rows 6–7: a 32-cell palette of every reachable value for the param. All six channel rows stay visible above it.

PICK setting one note step — palette on rows 6–7, chosen value at full, values used in this sequence dimly lit
  • Rows 6–7 = the 32 candidate values, low→high, left→right then down. The cell matching the step's current value is full-bright; other values already present elsewhere in this sequence glow dim so you can see the palette in use.
  • Press a value → writes it to the step and closes the picker.
  • Press the full-bright current value → removes the step (a toggle).
  • Tap another step on a visible channel row → hops the picker there; re-tap the open step to cancel.
Grid-reachable contract: every value randomize/mutate can produce lands exactly on one of these 32 cells, so anything the machine generates you can still see highlighted and re-edit by hand.

06PROB page — chance & alt-trig

Toggled by PROB (row 6, col 13). Rows 0–5 stay per-channel, but now control probability and how the B (alt) note layer triggers.

PROB per channel: note alt-trig · burst probability · burst/hit toggle
colscontroloptions
0–1note alt-trighold = B note drawn once per burst & summed onto every hit · step = advance B per hit (arpeggiates the alt pitch)

alt-trig "step" is how you arpeggiate: put a run of degrees in the B note sequence, set note alt-trig to step, and each hit in the burst advances to the next B offset on top of the held A degree.

07PERF page — reset · octave · rate

Toggled by PERF (row 6, col 12). Per-channel performance controls — none of these touch the value sequences themselves.

colscontroloptions

Why reset matters: copy a channel, give both reset = 1 bar, and they re-lock to the bar boundary each bar instead of slowly drifting apart.

08QNT page — per-channel quantize

Toggled by QNT (row 6, col 15). Each channel gets its own forward-snap grid: a burst's hits are nudged forward onto the next grid point before firing, so channels with different divisions can lock to different feels.

QNT per channel: one quantize value lit on cols 0–7
colscontroloptions
0–7quantize grid1/3 · 1/4 · 1/6 · 1/8 · 1/12 · 1/16 · 1/24 · 1/32 (events per whole note; higher = finer)

Tempo is never changed — only when a hit lands. Quantize is not sequenced, and randomize/mutate leave it alone. (On the screen it's folded onto the perf page.)

09OP page — per-operator timbre

Toggled by OP (row 6, col 11). The four-operator voice's static colour, per channel: each operator's frequency ratio and output level. This is where each channel's identity lives — it's not sequenced.

OP per channel: op1–4 ratio (cols 0–3) · op1–4 level (cols 8–11)
colscontroldoes
0–3op1–4 ratiooperator frequency ratio, from a curated set. op1 is the fundamental (default 1.0) but is editable like the rest. Tap a cell → value picker on rows 6–7.

The FM algorithm (operator routing), geode mode and amp env mode are engine-wide, not per-channel — set them in PARAMETERS ▸ VOICE alongside mod index, amp punch, fm feedback and fm drive.

Row 7 cols 11–15 are armed modes, not instant buttons. Press one (it fast-blinks), then tap a channel on row 6 to apply it. Press the action again to disarm.

Controls

E1 select channel (1–6)
E2 walk the cursor — on a sequence page it flows through run → every step of every param line (each ending in an _ add slot); on other pages it picks a line
E3 edit under the cursor — change the value, or on run turn right=launch / left=stop; turn a step below its lowest value to remove it; on _ turn right to append
K2 / K3 page back / forward through main · alt · perf · prob · scale · op
K1 left to the norns system menu
main = the A-layer sequences, alt = the B (offset) layer of note/level. The screen's page and the grid's mode buttons stay in sync. The screen's perf page also carries per-channel quantize (the grid keeps that on its own QNT page).

12Output routing

Every channel can drive the internal FM voice and/or external gear. This lives in the PARAMETERS menu (the OUTPUTS group) — there's no grid/screen page for it. External voices receive the final geode-bent freq / level / length.

destinationwhat it sends
audiothe internal Potionshop FM engine (default)
midinote on/off on an assignable device + channel; modwheel (CC1) carries brightness
audio + midiboth at once

crow 3+4v/oct pitch on output 3, AR envelope on output 4

Brightness here is a proxy — the largest active modulator ratio for the current algorithm. Tempo lives in the norns system CLOCK menu, not in the script (it uses whatever the clock is set to). Everything else is a script param, saved in PSETs and MIDI-mappable.
