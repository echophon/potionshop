The six params (row 7 · cols 0–5)

paramdoesrange
divhit spacing = 4/div beats1–32
repshits per burst (-1=∞)1–31,−1

Each param has its own A + B sequence per channel. B is an additive offset (adds value 0 = none).

Gestures

press a step→ step picker
press dim append slot→ add step + picker
in picker, press lit value→ remove step
press selected param again→ flip A⇄B
press a page button again→ back to MAIN
arm action, tap a channel→ apply it

Blink: fast = "you are here" (active page / armed action) · slow = latched (B layer, or a toggle that's on).

Actions (row 7 · cols 11–15)

CLRreset A seqs to default
COPYsnapshot A layer
PASTEwrite snapshot to A
RNDscramble (grid-reachable)
MUTnudge values ±

Armed, not instant: press to arm (blinks), tap a channel to apply. CLR/COPY/PASTE touch the A layer only.

Concepts in one line

  • burst = reps hits, 4/div apart, then repeat
  • sequins = looping value list, advances per burst
  • A/B = base seq + additive offset seq
  • geode = per-hit amp/ratio shaping curve
  • quantize = shared forward-snap grid
  • reset = rewind seqs every 1/2/4 bars
